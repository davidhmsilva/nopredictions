THE RULES THE AGENT FOLLOWS

1
No lookahead bias. Every data point used must have been available before kickoff. The agent can only use information a bettor would have had at the time.

CLV is king. Positive ROI with negative Closing Line Value = luck. Positive CLV with negative ROI (short-term) = potential edge. We always measure both.

Minimum 200 selections before any strategy conclusion. No cherry-picking a 15-bet hot streak.

All picks posted before kickoff. No retroactive claims. The agent puts its reasoning on the table before the match starts.
